# Catonut

Catonut is a simple starter project for building a modern web app or landing page.

## Contents

- `index.html` — page structure
- `style.css` — styling
- `script.js` — interaction logic

## Run locally

Open `index.html` in a browser, or serve the folder with a small local web server:

```bash
python -m http.server 8000
```

Then visit `http://localhost:8000`.

## Customize

Edit the HTML, CSS, and JavaScript files to build your app.
